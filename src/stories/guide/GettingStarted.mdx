# Handy Uploader

A file uploader for **Vue, React, Svelte, Angular and plain HTML**, with **automatic video thumbnails**, **image compression**, three layouts, and per-file **names, descriptions and tags**, translated into 5 languages.

<Canvas of={Uploader.ThumbnailView} />

## Three flavours, same options

| | `handy-uploader` | `handy-uploader/vuetify` | `handy-uploader/element` |
| --- | --- | --- | --- |
| **For** | Any Vue 3 app | Vue 3 apps using Vuetify 3 | React, Svelte, Angular, plain HTML, any framework |
| **Styling** | Plain CSS. Works with Tailwind, Bootstrap, your own CSS, or none | Vuetify components | The same plain CSS, added automatically |
| **Needs** | `vue` | `vue`, `vuetify`, `@mdi/font` | Nothing (Vue is bundled) |
| **In this Storybook** | [Vue (any CSS)](?path=/docs/vue-any-css-handyuploader--docs) | [Vue + Vuetify](?path=/docs/vue-vuetify-handyuploader--docs) | [Web Component](?path=/docs/web-component-handy-uploader--docs) |

All three have **the same options**, so switching is mostly a change of import. For the Web
Component in each framework, see [Framework Support](?path=/docs/guide-framework-support--docs).

## Install

```bash
npm install handy-uploader
```

### Without Vuetify

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { HandyUploader, type DocumentAttachment } from 'handy-uploader'
import 'handy-uploader/style.css'

const files = ref<DocumentAttachment[]>([])
</script>

<template>
  <HandyUploader
    v-model:document-attachment="files"
    file-uploader-type="thumbnail"
    file-accept="image/*,video/*,.pdf"
    :max-file-size="10 * 1024 * 1024"
    change-file-name
    add-file-description
    add-file-tag
    :tags="['invoice', 'contract', 'photo']"
  />
</template>
```

### With Vuetify

```ts
// main.ts: Vuetify must be installed in your app
import { createVuetify } from 'vuetify'
import 'vuetify/styles'
import '@mdi/font/css/materialdesignicons.css'
app.use(createVuetify())
```

```vue
<script setup lang="ts">
import { HandyUploader } from 'handy-uploader/vuetify'
</script>

<template>
  <HandyUploader v-model:document-attachment="files" file-uploader-type="table" />
</template>
```

## What you get back

`files` is an array of attachments. Each holds the file contents as base64, ready to send to your API:

```ts
interface DocumentAttachment {
  file: {
    name: string               // "report.pdf"
    format: string             // "pdf" ("jpg" after compression)
    base64: string             // contents, without the "data:…;base64," prefix
    size: number               // bytes
    tags: string[]
    description: string | null
    showDetailState: boolean
  }
}
```
