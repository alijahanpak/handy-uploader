# Feature Tour

Every feature of `HandyUploader`, and where to see it. Links open the framework-free version; each story also exists under **Vue + Vuetify** unless marked *(any CSS only)*.

## Adding files

| Feature | How | Try it |
| --- | --- | --- |
| Insert dialog | Click **Insert File**, then pick files or **drag them into the dialog** | [Playground](?path=/story/vue-any-css-handyuploader--playground) |
| Name, description and tags before adding | `change-file-name`, `add-file-description`, `add-file-tag` + `tags` | [Playground](?path=/story/vue-any-css-handyuploader--playground) |
| File count badge | `badge-counter` (red when the limit is reached) | [Thumbnail View](?path=/story/vue-any-css-handyuploader--thumbnail-view) |

## Validation

| Feature | How | Try it |
| --- | --- | --- |
| Maximum size per file (bytes) | `:max-file-size="2000000"` | [Restricted File Types](?path=/story/vue-any-css-handyuploader--restricted-file-types) |
| Maximum number of files | `:max-file-count="5"` | [Restricted File Types](?path=/story/vue-any-css-handyuploader--restricted-file-types) |
| Accepted types (also for dropped files) | `file-accept=".pdf,image/*"` | [Restricted File Types](?path=/story/vue-any-css-handyuploader--restricted-file-types) |

Rejected files show a message, and the other files in the same selection are still added. Without Vuetify, the `error` event also reports them.
