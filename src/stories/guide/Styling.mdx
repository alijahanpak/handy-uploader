# Styling & Theming

This page is about the **framework-free** `HandyUploader`. The Vuetify version follows your Vuetify theme.

## 1. Import the default theme

```ts
import 'handy-uploader/style.css'
```

## 2. Change it with CSS variables

Set them on the component or on any parent, for example your app's root:

```css
.hu-uploader {
  --hu-primary: #7c3aed;
  --hu-button-bg: #7c3aed;
  --hu-radius: 16px;
}
```

## 3. Dark mode

Add the `hu-dark` class to the component or any parent:

```vue
<div class="hu-dark">
  <HandyUploader v-model:document-attachment="files" />
</div>
```

## 4. Your own classes (Tailwind, Bootstrap, …)

Every part has a `hu-*` class, for example `hu-card`, `hu-button`, `hu-chip`, `hu-dialog` and `hu-table`. The built-in styles are **single-class selectors**:

- They **survive global resets** such as Tailwind's preflight or Vuetify's, so buttons and dialogs don't lose their styling.
- Overriding them is easy: a class of yours that comes later in the CSS, or one with one more class in its selector, wins.

```css
/* e.g. in your app.css, after importing handy-uploader/style.css */
.hu-card { border-radius: 0; box-shadow: none; border: 1px solid #ddd; }
```

## 5. No default theme at all

Skip `handy-uploader/style.css` and style the `hu-*` classes yourself, or replace whole cards with the `item` slot.

**Browser support:** the default theme uses `color-mix()` and `:has()` (Chrome/Edge 111+, Firefox 121+, Safari 16.4+). Older browsers still work, with simpler focus and badge styling.
